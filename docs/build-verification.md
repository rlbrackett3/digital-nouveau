## 3. Image Audit: WARNING

Several images referenced in the built HTML are missing from `dist/images/`.

### Missing Wix CDN Images

The built site references Wix-hosted images using paths like `/images/dc9b92_...`. These images were migrated from the Wix blog but were never downloaded to the local `dist/images/` directory.

- **Affected files:** `index.html`, `blog/index.html`, and ~130 individual blog post pages
- **Missing image pattern:** `/images/dc9b92_<hash>~mv2.jpg` (Wix CDN thumbnails)
- **Missing image pattern:** `/images/avatar-purple.jpg` (130+ references in blog index)
- **Total missing image references:** ~150 unique image files across the site

**Impact:** Images will not display when serving the site locally. This is expected if the site is deployed to a server/proxy that has access to the Wix CDN, or if images need to be manually copied before deployment.
