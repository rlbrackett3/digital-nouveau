## Overview & Context
Micro-lecture for Pratt Institute's ARCH202 Intermediate Design studios. Introduce architectural analysis through decompositional drawing and video-based representation. Core premise: Architecture can be analyzed as a functionally integrated system of interconnected and discrete elements using time-based media.

## Core Techniques
- **Decomposition Strategies:** X-Rays/MRIs, layered transparent systems, scans, overlays, fades, and exploded relationships.
- **Fixed Viewpoint:** Utilize oblique or axonometric projections.
- **Temporal Layering:** Layers become frames in time, decomposing the architecture sequentially.
- **Visual Organization:** Colors and tones organize differences and produce emphasis.

## Key Case Studies
- **Le Corbusier's Villa Savoye:** Student analysis using planar/volumetric color overlays.
- **OMA Projects:** Seattle Public Library, CCTV Headquarters.
- **Mies van der Rohe's Barcelona Pavilion:** Intro segments animated from the Representation 2 course.

> "All of you have at least 80% of the skills to put together a video-based analysis and narrative like this."
